# Contributing to Rocket-MCP

Rocket-MCP is currently a private Rocketpix working repository. It is not yet open for external
contributions or pull requests.

When the project is ready for a public release, this page will describe how to report issues, propose
features, and contribute code.

## About the fork

Rocket-MCP is based on [Figwright](https://github.com/awdr74100/figwright). Improvements that are
general-purpose rather than Rocketpix-specific may later be proposed to the Figwright project as
separate upstream contributions. The current difference log lives in [FORK.md](./FORK.md).

## Internal work

For people working inside Rocketpix, [AGENTS.md](./AGENTS.md) is the canonical guide to the
architecture, commands, and rules for changes.
